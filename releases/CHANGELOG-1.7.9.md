# 1.7.9

## 下载

* `metronav-mc1.20.4-1.7.9-guide.jar` — **Fabric 1.20.4**
* `metronav-forge-mc1.20.1-1.7.9.jar` — **Forge 1.20.1**（地图包用 1.8.0 的读取逻辑）

依赖：MTR 4.0.5（Fabric / Forge 对应版本）、Xaero's World Map（可选，装了才有地形层）。

## 地铁导航

* **到达判定改按站 id 锚定**：以“你点下去要去的那个站”为准，计划末点若停在前一站，会自动补一段步行到目标站。修复“在目的地的前一站就报到达”。
* **换乘提示修正**：
  * “准备下车 / 换乘”只在本段终点站成为当前目标时才提示，不再提前一站；
  * 站名取自**物理上最近的车站**，不再因为计划标签错位而“到了大风却说石碧”；
  * “下一站 X · 还有 N 站”的站名与站数一致（原来整体错开一站）。
* **站外换乘只允许在线路两端**：避免规划器为省几十秒把“再坐一站”换成“中途下车走一段”。
* **站台坐标带三重校验**：两端不能是 (0,0,0)、跨度 ≤400 格、中点须落在站点区 ±64 格内，任一不过就退回站点区中心。
* 地铁平均旅速可配置（默认 15 m/s，MTR 自带的 20 km/h 会让地铁永远算不过步行）。

## 步行

* **自动识别的步行走廊**：读世界方块撒点建图 + A*，绕开建筑/水；找不到路时退回直线并明确提示。
* 直线化简保留拐点、0.5 格采样避免切楼角；斜向移动要求两侧可通，防止贴墙撞停。
* 走不动时跳过够不着的路点；偏离持续一段时间后从当前位置自动重新规划。
* HUD 增加“距离剩余 / 距下一站 / 预计剩余时间”，偏离提示区分“正在指回路线”与“已按当前位置重新规划”。

## 地图与平台

* Xaero 数据支持 `xaero/world-map`（新布局）、`XaeroWorldMap`（旧布局）、`config/xaero/...`，并跨版本隔离目录（当前 / 父级 / 祖父级）查找。
* 区域文件兼容 `0_0.zip` 与 `r.0.0.zip` 两种命名、`.zip` 与 `.xwmc` 两种格式。
* **Forge 1.20.1 移植**：入口、按键、tick/HUD/世界渲染改用 Forge 事件，其余逻辑与 Fabric 版共用同一份源码。

## 已知问题

* 地铁进度仍以几何距离推进，车站坐标系整体偏移较大时可能提前/延后一站；下一步打算改成“沿线路里程”模型（HowToGo 的做法）。
* 步行路网是 2.5D 网格，没有桥/隧道/立交分层；长距离（>800 格）规划会变慢，靠节点上限兜底退回直线。
